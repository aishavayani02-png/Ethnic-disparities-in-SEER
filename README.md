## Shiny app

This repository includes a Shiny app (`app.R`) that visualizes standardized relative survival, mediation analysis, and avoidable deaths estimates stored in `Shiny.csv`.

### Run locally

1. Open `app.R` in RStudio.
2. Install required packages if prompted.
3. Click **Run App**.

### Use data from GitHub

To read the data directly from GitHub, update the `data_source` value near the top of `app.R` to a raw GitHub URL (for example, `https://raw.githubusercontent.com/<username>/<repo>/main/Shiny.csv`).
